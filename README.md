# CodeAlpha_Calculator

A simple command-line calculator written in C as part of my CodeAlpha C Programming Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Repeat calculations without restarting

## Concepts Used

- switch-case
- Functions
- Loops
- Basic input/output

## How to Compile

```bash
gcc calculator.c -o calculator
```

## How to Run

```bash
./calculator
```

## Example

```
Enter first number : 10
Enter operator (+, -, *, /): /
Enter second number: 0
Error: Division by zero is not allowed.

Enter first number : 6
Enter operator (+, -, *, /): *
Enter second number: 7
Result: 6 * 7 = 42
```
